### Wails v3
- Role: The frontend is a Go + Vue desktop app built with Wails v3; the `frontend/` directory is the Wails project root (Vite-based Vue 3) and Go bindings under `frontend/bindings/wailsapp/wails/v3/` are generated by Wails.
- Integration point: `frontend/package.json` declares the Wails dependency; `main.js` boots the Wails application; Go-side code in `internal/bridge/` exposes window, proxy, and ad bridge methods to the JS side via Wails' binding mechanism.
- Stable shape: Go structs/functions intended for the UI are exposed through Wails' generated bindings; the JS side consumes them as native modules. Verify exact API surface against the official Wails v3 docs.
