## Approach

The frontend (`frontend/`) is a **Vue 3** desktop application built with **Vite** and embedded via **Wails**. Visual styling is driven by **Tailwind CSS v3.4** (with PostCSS + Autoprefixer), augmented by the `@iconify/tailwind` plugin for dynamic icon class generation. There is no separate component library or design-token system beyond Tailwind's theme extension; styles are composed directly in `.vue` templates using Tailwind utility classes, with a small set of hand-written global CSS for cross-browser scrollbars, font loading, and layout helpers.

## Key Files

- `frontend/tailwind.config.cjs` — Tailwind configuration: custom `primary` color palette (10–950 shades plus DEFAULT `#1677ff`), `fontFamily.num`, extended `fontSize` (xs/sm/lg) and `zIndex` (999/9999/99999), safelisted icon prefixes from Ant Design, Boxicons, Material Icons, Logos, Mingcute, etc., and `addDynamicIconSelectors` plugin.
- `frontend/src/style/global.css` — Global resets: `html/body/#root` sized to `100vh/100vw` with `overflow: hidden`, dark background `#191919`, text color `#f7f7f7`, base font size `13px`; loads `PingFang-Medium` via `@font-face`; defines `color-scheme: dark`; thin native scrollbar styles for Firefox and WebKit; mask-image based `.scroll-shadow` / `.scroll-shadow-bottom` fade effects; extensive `.no-flex-gap .flex.gap-*` rules that replace Tailwind `gap-*` with explicit `margin-left`/`margin-top` values (for compatibility with older flexbox gap behavior).
- `frontend/src/style/tailwind.css` — Tailwind entry: `@tailwind base/components/utilities`; registers `HFKos` font; exposes CSS variable `--font-num` in `@layer base`; defines two reusable component-layer utilities `.center-row` and `.center-col` via `@apply`.
- `frontend/postcss.config.cjs` — PostCSS pipeline: `tailwindcss` then `autoprefixer`.
- `frontend/package.json` — Dependencies include `vue 3.5`, `vue-router 4.6`, `chart.js` + `vue-chartjs`, `@floating-ui/dom`, `sortablejs`, `dayjs`, `@wailsio/runtime`; dev deps include `vite 7.1`, `tailwindcss 3.4`, `@iconify/tailwind`, `@vitejs/plugin-vue(-jsx)`; browserslist targets `Safari >= 13`.
- `frontend/src/components/ui/*.vue` — Primitive UI components (`Button.vue`, `Card.vue`, `Combobox.vue`, `ContentModal.vue`, `Input.vue`, `InputModal.vue`, `MessageProvider.vue`, `Modal.vue`, `Select.vue`, `Switch.vue`, `Tooltip.vue`).
- `frontend/src/views/Home.vue` — Example page composing `Button`, `Card`, and domain cards.

## Architecture and Conventions

### Theme tokens
- The only centralized color token is `primary` (a blue scale centered on `#1677ff`), defined in `tailwind.config.cjs`. Most other colors are written as raw hex literals in component templates (e.g. `bg-[#292929]`, `border-[#343434]`, `text-[#a3a3a3]`, `bg-gradient-to-b from-[#1D8010] to-[#25B433]`).
- Fonts: `PingFang-Medium` is the default body font (loaded in `global.css`); `HFKos` is used for numeric display via the `num` font family and the `--font-num` CSS variable.
- Base typography: `font-size: 13px` globally; Tailwind overrides define `xs: [12px, 16px line-height]`, `sm: [13px, 18px]`, `lg: [20px, 28px]`.
- Z-index scale: defaults extended to `999`, `9999`, `99999` (safelisted to prevent tree-shaking).

### Component styling model
- Components under `src/components/ui/` are **unstyled primitives**: they accept props (e.g. `variant` on `Button`, validated against `["default", "primary", "text"]`) and render Tailwind utility classes inline in the template. There is no CSS-in-JS, no SCSS per component, and no external UI kit.
- Layout composition uses Tailwind's flex utilities (`flex`, `flex-col`, `items-center`, `justify-between`, `gap-*`) together with the custom `.center-row` / `.center-col` helpers from `tailwind.css`.
- Icons are referenced via the `icon-[...]` syntax generated by `@iconify/tailwind` (e.g. `icon-[mdi--play]`, `icon-[bxl--openai]`, `icon-[ant-design--bilibili-outlined]`), with an explicit safelist in `tailwind.config.cjs`.

### Global CSS strategy
- All global styles live in `src/style/global.css` and `src/style/tailwind.css` (the latter only holds Tailwind directives and two layer components). No scoped `<style>` blocks are used in the sampled components.
- Scrollbar customization is deliberately cross-browser: Firefox `scrollbar-width`/`scrollbar-color`, WebKit pseudo-elements `::-webkit-scrollbar*`, and mask-image gradients for fade-out at scroll edges.
- A large block of `.no-flex-gap .flex.gap-*` selectors maps Tailwind spacing tokens to explicit pixel margins, indicating the app needs deterministic gutters across flexbox implementations.

### Build integration
- Vite is the bundler; Tailwind scans `./index.html` and `./src/**/*.{vue,js,jsx,ts,tsx}` via its `content` config.
- PostCSS runs Tailwind then Autoprefixer; browserslist restricts output to `Safari >= 13`.
- Wails runtime (`@wailsio/runtime`) is used for IPC events (`Events.On(...)`) but does not affect styling.

## Conventions and Constraints

- **Utility-first styling**: Component visual appearance is expressed almost entirely through Tailwind utility classes in `.vue` templates rather than dedicated CSS files. This is observed consistently in `Button.vue`, `Card.vue`, and `Home.vue`.
- **Dark-only theme**: `color-scheme: dark` is set in `global.css`; the root background is `#191919` and text is light (`#f7f7f7` / `#e5e5e5` / `#a3a3a3`). No light-mode toggle exists in the codebase.
- **Primary brand color**: The `primary` Tailwind color (blue `#1677ff` DEFAULT) is the only named semantic color token; other colors are hard-coded hex literals in templates.
- **Font stack**: Body text uses `PingFang-Medium`; numeric/text display uses the `num` family (`HFKos`, `PingFang-Medium`, system fonts). Both fonts are bundled as `.ttf` assets under `src/style/fonts/` and loaded via `@font-face`.
- **Iconography**: Icons come from Iconify collections (Material Design Icons, Boxicons, Ant Design, Logos, Mingcute) selected via the `icon-[collection--name]` class pattern enabled by `@iconify/tailwind`; every icon used must be present in the safelist in `tailwind.config.cjs`.
- **Z-index tiers**: Modal-like overlays use the extended z-index values `z-999`, `z-9999`, `z-99999` (also safelisted).
- **Flex gap workaround**: When Tailwind's native `gap-*` is insufficient, the `.no-flex-gap` modifier class is applied alongside `gap-*` to force explicit margin-based spacing via the rules in `global.css`.
- **Component prop contracts**: UI primitives declare typed props with validators (e.g. `Button.variant` restricted to `default | primary | text`), establishing a small internal API surface for styling variants.
