The root `main.go` is the sole executable: it initializes logging and launches the Wails app, which embeds the compiled Vue frontend (`frontend/dist`) and static assets via `//go:embed`. Sibling directories are independent Go modules or toolchains rather than imported packages — they communicate with the desktop shell through configuration files (BYOK token, upstream URL, proxy settings) and shared prompt/tool catalogs under `prompts/`, not through Go imports. `Taskfile.yml` is the cross-child orchestrator: it includes per-OS taskfiles under `build/{windows,darwin,linux}/` plus `build/Taskfile.yml` to build the frontend, package multi-arch binaries, generate update manifests from `release-notes.md`, and publish GitHub Releases. The tab server and debugger run as separate processes invoked by tasks; the proto extraction pipeline in `proto_and_generated/` is a one-shot tool that keeps canonical `.proto` snapshots aligned with Cursor's bundled JS extensions consumed at runtime by the shell.
