Built as a standalone binary via `go build -o bin/cursor-proxy-debugger ./cmd/cursor-proxy-debugger` or run with `go run ./cmd/cursor-proxy-debugger`; defaults are proxy `127.0.0.1:9090`, UI `127.0.0.1:9091`, target `api2.cursor.sh`, max 200 exchanges and 2 MiB capture per side. Requires manually configuring Cursor's network proxy and trusting the downloaded CA from `http://127.0.0.1:9091/api/ca.crt`.
