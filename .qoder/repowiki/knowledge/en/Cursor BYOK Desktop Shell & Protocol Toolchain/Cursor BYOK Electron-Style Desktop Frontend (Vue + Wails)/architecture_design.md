Single-page Vue 3 application bootstrapped from `src/main.js`, mounted into `#root` via `createApp(App)`. Layering inside `src/`:
- `components/ui/*` — headless-ish primitives (Button, Card, Modal, Input, Select, Switch, Tooltip, Combobox, ContentModal, InputModal, MessageProvider).
- `components/*.vue` — domain widgets composing UI primitives (AdModelProvider, CursorAccountCard, HomeMetricsCard, LocaleSelect, ModelAdapterModal, ModelEditor, ModelAdapterTestCard).
- `views/` — page-level components (`Home.vue`, `Config.vue`, `ModelConfig.vue`) rendered by `router/index.js` using `createWebHashHistory`.
- `state/appState.js` — single reactive store exposing `appState` / `appViewState`; persists to `localStorage` under key `cursor-client:runtime-state:v2` via `watchSyncEffect`.
- `services/clientApi.js` — thin HTTP-free facade over `@wailsio/runtime`'s `Call.ByName`, re-exporting typed bindings from `@bindings/cursor/internal/bridge/*` (proxyservice, adservice, metricsservice, windowservice).
- `composables/` — shared composition functions (`useModal`, `useInputModal`, `useMessage`, `useConfigTransfer`).
- `i18n/` — runtime locale loader plus a custom Vite plugin (`plugins/static-i18n-plugin.js`) that scans source files at build time, extracts Chinese text, generates `src/i18n/generated/catalog.json` and per-locale JSON files in `src/i18n/locales/`.

Build pipeline: `vite.config.js` registers `@wailsio/runtime/plugins/vite` (which reads `bindings/` to generate JS FFI wrappers), `code-inspector-plugin` in dev, `topLevelAwait`, and the custom `staticI18nPlugin`. The `scripts/run-vite-build.mjs` wrapper forwards `--scan` to set `STATIC_I18N_SCAN=true`, triggering catalog generation before the actual Vite build. `bindings/` is auto-generated by the Wails toolchain and mirrors Go service packages (`ads`, `backend/server/config`, `bridge`, `client`, `cursoraccount`, `updater`) as JS modules with paired `index.js` + `models.js` files; `clientApi.js` imports only the public surface of `bridge/proxyservice`, `adservice`, `metricsservice`, `windowservice`.
