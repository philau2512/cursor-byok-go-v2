`task dev` starts the Wails dev server on port 9245 (configurable via `WAILS_VITE_PORT`). `task build` builds the current OS bundle; `task build:all` builds macOS arm64/amd64 and Windows 386/amd64 from macOS only. `task release:prepare` (macOS/Linux) builds all release assets and generates `update.json`; `task release:github` publishes to GitHub Releases after verifying assets and syncing README to `leookun/cursor-byok`.
