Single-package Go binary (`main.go`) acting as an `http.Handler` server listening on `:8041`. Request routing is path-based via the in-memory `defaultUpstreamTargets` map (e.g. `/aiserver.v1.AiService/StreamCpp` → `https://api4.cursor.sh:...`), so each incoming URL path is looked up and forwarded to a fixed upstream host. The `serverApp` struct holds the parsed config (token from `config.yaml`), an `*http.Client`, and a cloned copy of the target map. On each request, body is read into memory for non-GET/HEAD/DELETE methods, hop-by-hop headers are stripped via the `hopByHopHeaders` set, a `Bearer <token>` Authorization header is injected, and a computed `x-cursor-checksum` header (timestamp + SHA256 of the authorization) is added before calling the upstream; responses are streamed back with chunked flushing. Configuration is loaded once at startup from `./config.yaml` using `gopkg.in/yaml.v3`. Deployment is a two-stage Dockerfile building a static CGO-disabled binary from `scratch` with CA certs.
