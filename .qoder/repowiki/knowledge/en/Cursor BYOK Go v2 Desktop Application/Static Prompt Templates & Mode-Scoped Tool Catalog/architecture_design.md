The package is a read-only asset loader built around the `Mode` enum (`ask`, `plan`, `agent`, `debug`, `multitask`, `subagent`) declared in `embed.go`. All static files — `<mode>/prompt.md`, `plan/system_reminder.txt`, `debug/system_reminder_initial.txt`, `debug/system_reminder_continuing.txt`, `compaction/prompt.md`, `commit/prompt.md`, plus `tools.json` and `modes/*.json` manifests — are compiled into an `assetFS embed.FS` via a single `//go:embed` directive. `init()` pre-caches every prompt and assembled tools array into package-level maps (`cachedPrompts`, `cachedTools`, `cachedDebugInitialReminder`, etc.) so subsequent reads are zero-allocation. Per-mode tool selection goes through `assembleModeTools`: it resolves each manifest entry against `tools.json` using a three-tier priority — explicit `{name, variant}` → `<tool>.<mode>` key → canonical `<tool>` name — returning a compacted JSON array of selected tool definitions. `render.go` provides `RenderPromptTemplate`, which substitutes `{{FAKE_MODEL_ID}}` / `{{FAKE_MODEL_NAME}}` placeholders with the runtime model name. Dependency direction is one-way outward: callers consume pure accessor functions; there are no runtime dependencies beyond the standard library.
