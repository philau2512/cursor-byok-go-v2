The package is organized around a `Mode` enum (`ask`, `plan`, `agent`, `debug`, `multitask`, `subagent`) that indexes into an embedded filesystem (`assetFS` declared in `embed.go` via `//go:embed`). Static assets live under mode-scoped directories (`ask/prompt.md`, `plan/prompt.md`, `compaction/prompt.md`, `commit/prompt.md`, `debug/system_reminder_initial.txt`, etc.) plus a shared `tools.json` catalog. Per-mode tool selection is driven by `modes/<mode>.json` manifests that reference canonical tools by name or `<tool>.<variant>` keys resolved against the `variants` map in `tools.json`. The `init()` function pre-caches all prompts and assembled tool JSON arrays into package-level maps so callers get zero-allocation reads. Public API pairs a `Read*` (returns error) with a `MustRead*` (panics on failure) for every asset type. `render.go` provides `RenderPromptTemplate`, which replaces `{{FAKE_MODEL_ID}}` / `{{FAKE_MODEL_NAME}}` placeholders with the runtime model name. Dependency direction is one-way: this module exposes pure read-only accessors; it has no runtime dependencies beyond the standard library.
